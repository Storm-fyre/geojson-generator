⚙️ Quality Tuning Guide

🎨 Color Tolerance (Default: 15)

Controls how forgiving the color matcher is against scanner noise, paper grain, and JPEG compression.

Tip: If regions appear patchy or full of holes, increase this. If colors bleed into neighboring different colors, decrease it.

📏 Filter Thin Lines (Default: 3px)

Bridges across thin black state lines, rivers, and coordinate grids cutting through colored regions.

Tip: If dashed lines or rivers slice your polygon in half, increase to 5px so it automatically heals over the gap.

🧹 Min Polygon Area (Default: 15 px)

The dust and speckle filter. Deletes rogue clusters smaller than this number of pixels.

Tip: Prevents thousands of microscopic speckles from cluttering your exported GeoJSON.

✨ Boundary Smoothing (Default: 1.0)

The Douglas-Peucker simplification tolerance. Converts pixelated "staircase" edges into smooth vector curves.

Tip: Higher values create lighter file sizes and smoother boundaries. Lower values trace every single raw pixel.

👁️ Overlay Opacity (Default: 0.45)

Adjusts the visual transparency of the vector preview overlay on canvas to compare alignment with the underlying map.
